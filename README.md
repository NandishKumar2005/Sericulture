# Smart Sericulture Project

AI-Powered Precision Sericulture and Production Forecasting System.

## Project Overview

Smart Sericulture is an AI-powered mobile decision-support system designed to assist farmers throughout the sericulture production cycle, incorporating mulberry harvest scheduling, leaf quality assessment, dynamic silkworm feeding optimization, cocoon & silk yield prediction, and an interactive AI copilot.

## Repository Structure

```text
smart-sericulture/
├── mobile/          # React Native / Expo mobile application
├── backend/         # Node.js + Express REST API backend
├── ml-service/      # Python FastAPI service for AI/ML models & Copilot RAG
├── web/             # Public landing page & web portal (React + Vite)
├── ml-models/       # Serialized ML model artifacts
├── datasets/        # Datasets for harvest, leaf images, feeding, cocoon & silk
├── docs/            # Architecture, API specifications, and research docs
├── PROJECT_SPEC.md  # Detailed functional & technical requirements specification
└── README.md
```
